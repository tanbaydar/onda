## Chapter doctrine

- Whitespace is functional when it communicates grouping, focus, rhythm, or readable measure.
- Density is a product and task decision, not an accident.
- Repeated values come from a nonlinear scale with meaningful steps.
- Content width follows the content's needs, not the viewport's maximum.
- Fixed, fluid, and capped dimensions are selected intentionally.
- Responsive design recomposes relationships; it does not uniformly zoom them.
- Space within a group is smaller than space around the group.

## Layout evidence

Every layout change should be checked with:

- The narrowest supported width.
- A typical mobile width.
- A breakpoint boundary on both sides.
- A typical desktop width.
- A wide desktop width when containers or columns are affected.
- Sparse, typical, and dense content.
- Long labels, long prose, and missing optional content.
