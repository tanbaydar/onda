## Chapter doctrine

- Use a constrained role-based scale; do not accumulate arbitrary sizes.
- Choose fonts for legibility, intended use, available styles, and product character.
- Fit layout to readable text, not text to leftover layout width.
- Align mixed type by the baseline when it shares a line.
- Increase line height for smaller type and longer lines; reduce it for large headings.
- Link treatment follows context and hierarchy.
- Alignment follows reading direction and comparison needs.
- Trust the typeface’s spacing by default; adjust only for known display or all-caps cases.
