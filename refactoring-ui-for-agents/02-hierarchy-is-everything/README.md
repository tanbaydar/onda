# Hierarchy Is Everything

Visual hierarchy is the primary diagnostic for an interface that feels noisy, amateur, or undirected. It describes how important elements appear relative to one another.

## Chapter outcome

An agent should be able to:

- Name the primary, secondary, tertiary, and supporting elements.
- Create separation between those levels without extreme font sizes.
- Reduce competition before adding emphasis.
- Present data without mechanical label/value repetition.
- Preserve semantic HTML while styling for the real visual role.
- Balance heavy icons, borders, and text using contrast and weight.
- Style actions by importance and context, including destructive actions.

## Hierarchy test

Blur, squint at, or reduce the rendered interface to a thumbnail. The major visual masses should still reveal:

1. Where the user begins.
2. What content or action dominates.
3. Which information supports it.
4. Where the reading path ends.

If everything forms one uniform wall, the design fails before color or polish is considered.
