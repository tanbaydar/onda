## Translation choices

- Human-oriented encouragement became deterministic agent procedures.
- Before/after screenshots became observable failure conditions and comparison tests.
- Suggested values became starting heuristics, never unscoped product tokens.
- Subjective phrases such as “looks right” became explicit comparison sets, role assignments, and evidence requirements.
- Product-specific design authority always outranks this general memory.
