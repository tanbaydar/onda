# Leveling Up

This chapter turns visual references into reusable knowledge instead of copied styling.

## Read order

1. [Study unexpected decisions](./01-study-unexpected-decisions.md)
2. [Rebuild interfaces deliberately](./02-rebuild-interfaces-deliberately.md)

## Chapter doctrine

- Study decisions that violate your default assumptions.
- Explain why a reference works before borrowing from it.
- Rebuild without inspecting implementation so visual reasoning stays active.
- Compare your reconstruction to the source and extract reusable principles.
- Never copy a reference into a product without checking task, content, authority, accessibility, and system fit.

## Learning output

Every study should produce a small observation record:

- Reference and context.
- Unexpected decision.
- User or hierarchy problem it solves.
- Mechanism used.
- Conditions under which it works.
- Conditions under which it would fail.
- Existing modules it extends or challenges.
