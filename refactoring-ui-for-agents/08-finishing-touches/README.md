## Entry gate

Do not add finishing treatments until all answers are yes:

- Is the primary content/action immediately clear?
- Are related and unrelated elements grouped correctly?
- Does the surface use approved type, spacing, color, and component systems?
- Are text and controls accessible under current product requirements?
- Do mobile, desktop, sparse, dense, empty, loading, and error states work?
- Is real or representative media present?

If any answer is no, route back to the relevant foundation chapter.

## Finish rule

Every flourish must have a named target, restrained scope, approved visual channel, and verification that it does not create a second primary focus. “It looked plain” is a prompt to diagnose, not sufficient justification.
