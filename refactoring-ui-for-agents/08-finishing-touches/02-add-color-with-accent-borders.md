# Add Color with Accent Borders

## Use this module when

- A restrained surface needs one small color anchor.
- Active navigation, alerts, selected regions, headings, or page identity need an accent.
- Photography or illustration is unavailable or inappropriate.
- Product authority permits accent color in the intended role.

## Objective

Add a small, controlled color signal through a border or short rule without increasing component count or visual mass.

## Rules

1. Accent borders must correspond to meaning, selection, state, or identity—not random decoration.
2. Use an existing semantic or brand color token.
3. Keep the colored area small relative to the content.
4. Do not make the border the only signal for essential state.
5. Maintain consistent placement for repeated meanings.
6. Avoid applying accent borders to every component; scarcity is the effect.

## Procedure

### 1. Confirm color ownership

Check the product’s allocation rules. If the accent color is reserved for judgment, error, selection, or another role, do not repurpose it.

### 2. Choose the target

Valid targets may include the top edge of a highlighted panel, start edge of an alert, active navigation indicator, short rule beneath a heading, or global identity strip.

### 3. Choose geometry

Use an approved border thickness, radius relationship, and length. A short accent may create less visual mass than a full edge.

### 4. Add redundant state cues

For active/error/selected meaning, pair the border with text, weight, icon, accessible state, or position.

### 5. Check the whole page

Ensure only the intended target receives increased attention and that multiple accents do not fragment the reading path.

## Failure modes

- Different accent colors on unrelated cards.
- Full rainbow borders used to make a plain system exciting.
- Active tab indicated only by a colored line.
- Border thickness inconsistent with the system.
- Accent placed on low-priority content, creating false hierarchy.
- A color reserved for status reused decoratively.

## Verification

- The accent has a named semantic or identity role.
- Meaning survives grayscale.
- Placement and thickness are consistent across repetitions.
- Contrast and focus requirements remain satisfied.
- The page retains one primary focal path.
- Removing the border does not expose broken grouping or spacing.
