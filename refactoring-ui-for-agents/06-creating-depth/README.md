## Chapter doctrine

- Depth is a spatial model, not a generic polish effect.
- One interface should imply one consistent light direction.
- Shadow size corresponds to elevation and attention.
- Elevation comes from a small system, not bespoke component recipes.
- Direct and ambient shadow components may be controlled separately.
- Flat interfaces can express layers through color, spacing, solid offsets, and overlap.
- Overlap must preserve content clarity, responsive stability, focus visibility, and media separation.

## Permission check

Before using this chapter, inspect product authority. Some design systems intentionally prohibit shadows, gradients, or dimensional effects. In that case, use only the authorized flat-depth techniques and do not treat the book’s available tools as permission to introduce them.
