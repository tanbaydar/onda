# Even Flat Designs Can Have Depth

## Use this module when

- Product authority prohibits or minimizes shadows and gradients.
- Flat surfaces blend together.
- Agents are adding borders everywhere to create structure.
- A control or panel needs subtle raised/inset distinction.

## Objective

Communicate spatial relationships using color, solid offsets, overlap, and spacing while preserving a flat visual language.

## Rules

1. Depth does not require blur, gradient, or realism.
2. Relative surface lightness can imply raised or inset position.
3. A small solid offset shadow can separate an object while remaining graphic and flat, if authorized.
4. Spacing and overlap can establish layers without any shadow.
5. Flat-depth cues still need a coherent hierarchy and semantic role.
6. Do not equate “flat” with “every region has the same surface.”

## Procedure

### 1. Name the spatial relationship

Decide whether an element is base, grouped, raised, selected, inset, or overlaying. If there is no spatial distinction, do not manufacture one.

### 2. Try surface contrast

Use an approved lighter surface to imply lift or a darker/tinted surface to imply inset. Validate contrast and theme behavior.

### 3. Try spacing

Increase separation between groups or give the raised region clear surrounding space. This may eliminate the need for any outline.

### 4. Try a solid offset

Where the product’s graphic language supports it, use a short no-blur offset in a controlled direction. Map it to a token rather than a one-off effect.

### 5. Try overlap

Use [Overlap elements](./05-overlap-elements-to-create-layers.md) when two regions genuinely belong to different layers.

## Failure modes

- Replacing every shadow with a dark border.
- Using surface colors too similar to perceive or too contrasty for hierarchy.
- Solid offsets that look like accidental misalignment.
- Assigning different backgrounds to unrelated regions without grouping purpose.
- Flat overlays that obscure content because layer boundaries are unclear.
- Using depth color as the only interaction signal.

## Verification

- Spatial roles remain clear without blur or gradient.
- Surface colors fit the approved palette and contrast requirements.
- Borders are reduced rather than multiplied.
- The same layer model works in all supported themes.
- Focus and selection remain independently visible.
- Depth treatment disappears cleanly when no distinction is needed.
